Cara Membuka File GPX di iPhone dan Android

Import GPX routes from Mail, Files, or Safari into GPX Viewer.

2 September 2026

iOS dan Android tidak menyertakan penampil peta GPX bawaan. Anda memerlukan aplikasi sepertiPenampil GPXyang memahami.gpxformat. Setelah diinstal, mengimpor rute memerlukan beberapa ketukan melalui lembar berbagi.

Buka GPX di iPhone

Dari Mail atau File

  1. Temukan.gpxlampiran atau file.
  2. MengetukShare.
  3. SelectPenampil GPX.
  4. The route appears on the map immediately.

From Safari

Tap a GPX download link on a trail website, then share the downloaded file to GPX Viewer from Safari's download manager or save it to Files first.

Apple Maps cannot open GPX

Apple Maps does not import GPX files. Use GPX Viewer instead — it shows the full track, elevation profile, and waypoints on standard, satellite, or hybrid maps.

Buka GPX di Android

  1. Buka lampiran GPX di Gmail atau pengelola file Anda.
  2. MengetukBuka denganatauShare.
  3. MemilihPenampil GPX.
  4. SelectSelalujika diminta, untuk impor yang lebih cepat nanti.

Pemecahan masalah

  • Jenis file salah— konfirmasi ekstensinya.gpx, bukan.kmlatau.tcx.
  • Aplikasi tidak ada di menu Bagikan— buka GPX Viewer sekali, lalu coba lagi.
  • Jalur kosong— file mungkin berisi metadata tetapi tidak ada titik GPS; mengekspor ulang dari aplikasi sumber.
  • File terlihat salah di peta- melihatcara melihat GPX di peta.
