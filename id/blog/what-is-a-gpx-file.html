Apa itu File GPX?

Pahami Format Pertukaran GPS dan alasan file .gpx mendukung navigasi luar ruangan.

2 September 2026

Jika Anda telah mengunduh jalur pendakian, menerima rute bersepeda dari teman, atau mengekspor rekaman GPS dari jam tangan, Anda hampir pasti pernah menjumpai aberkas GPX. Ekstensi.gpxsingkatan dariFormat Pertukaran GPS— terbuka standar yang memungkinkan perangkat dan aplikasi berbagi data lokasi dengan cara yang dapat dibaca oleh alat apa pun yang kompatibel.

Apa isi file GPX?

Kebanyakan file GPX menyertakan satu atau lebih elemen berikut:

  • Trek— jalur yang terbuat dari titik-titik GPS, sering kali direkam saat mendaki atau berkendara.
  • Rute— jalur terencana dengan belokan penting untuk navigasi.
  • Titik arah— tempat menarik seperti pertemuan puncak, tempat perkemahan, atau tempat parkir.
  • Data ketinggian— ketinggian di atas permukaan laut pada setiap titik.
  • Stempel waktu— ketika setiap poin dicatat.

Aplikasi khusus sepertiPenampil GPXmenjadikan data itu sebagai peta interaktif. Melihatcara melihat GPX di petauntuk alur kerja penuh.

Trek GPX vs. rute

Amelacakadalah sesuatu yang telah Anda lalui — perangkat Anda mencatat setiap perbaikan GPS. Arutedirencanakan sebelumnya, menghubungkan titik arah ke mana Anda ingin pergi. Keduanya bekerja dengan cara yang sama di GPX Viewer: impor file dan ikuti garis di peta.

GPX vs KML, TCX, dan FIT

Aplikasi luar ruangan menggunakan beberapa format file GPS. Inilah saatnya GPX adalah pilihan yang tepat:

  • GPX— terbaik untuk berbagi rute hiking dan bersepeda antara aplikasi dan ponsel.
  • KML— umum di Google Earth; kurang ideal untuk navigasi jalur belokan demi belokan.
  • TCX— Format pelatihan Garmin dengan data detak jantung dan irama.
  • BUGAR— rekaman aktivitas biner dari jam tangan Garmin; tidak dimaksudkan untuk berbagi rute.

Untuk mengikuti jejak dan perencanaan rute di ponsel Anda, GPX adalah format yang digunakan. Penampil GPX terbuka.gpxfile secara langsung — tidak ada langkah konversi.
