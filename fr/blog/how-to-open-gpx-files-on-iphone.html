Comment ouvrir des fichiers GPX sur iPhone et Android

Importez des itinéraires GPX depuis Mail, Files ou Safari dans GPX Viewer.

2 septembre 2026

iOS et Android n'incluent pas de visionneuse de carte GPX intégrée. Vous avez besoin d'une application commeVisionneuse GPXqui comprend le.gpxformat. Une fois installé, l'importation d'un itinéraire nécessite quelques clics via la feuille de partage.

Ouvrez GPX sur iPhone

À partir d'un courrier ou de fichiers

  1. Trouver le.gpxpièce jointe ou fichier.
  2. RobinetPartager.
  3. SélectionnerVisionneuse GPX.
  4. L'itinéraire apparaît immédiatement sur la carte.

Depuis Safari

Appuyez sur un lien de téléchargement GPX sur un site Web de trail, puis partagez le fichier téléchargé avec GPX Viewer depuis le gestionnaire de téléchargement de Safari ou enregistrez-le d'abord dans Fichiers.

Apple Maps ne peut pas ouvrir GPX

Apple Maps does not import GPX files. Use GPX Viewer instead — it shows the full track, elevation profile, and waypoints on standard, satellite, or hybrid maps.

Ouvrez GPX sur Android

  1. Ouvrez la pièce jointe GPX dans Gmail ou votre gestionnaire de fichiers.
  2. RobinetOuvrir avecouPartager.
  3. ChoisirVisionneuse GPX.
  4. SélectionnerToujourssi vous y êtes invité, pour des importations plus rapides plus tard.

Dépannage

  • Mauvais type de fichier— confirmez que l'extension est.gpx, pas.kmlou.tcx.
  • L'application n'est pas dans le menu Partager- ouvrez GPX Viewer une fois, puis réessayez.
  • Piste vide— le fichier peut contenir des métadonnées mais pas de points GPS ; réexporter depuis l'application source.
  • Le fichier ne semble pas correct sur la carte- voircomment afficher GPX sur une carte.
