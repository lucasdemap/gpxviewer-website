Come aprire file GPX su iPhone e Android

Importa percorsi GPX da Mail, File o Safari nel visualizzatore GPX.

2 settembre 2026

iOS e Android non includono un visualizzatore di mappe GPX integrato. Hai bisogno di un'app comeVisualizzatore GPXche capisce il.gpxformato. Una volta installato, l'importazione di un percorso richiede pochi tocchi attraverso il foglio di condivisione.

Apri GPX su iPhone

Da posta o file

  1. Trova il.gpxallegato o file.
  2. RubinettoCondividere.
  3. SelezionareVisualizzatore GPX.
  4. Il percorso appare immediatamente sulla mappa.

Da Safari

Tocca un collegamento per il download GPX su un sito Web di sentieri, quindi condividi il file scaricato su GPX Viewer dal download manager di Safari o salvalo prima in File.

Le mappe di Apple non possono aprire GPX

Apple Maps non importa file GPX. Utilizza invece GPX Viewer: mostra la traccia completa, profilo altimetrico e waypoint su mappe standard, satellitari o ibride.

Apri GPX su Android

  1. Apri l'allegato GPX in Gmail o nel tuo file manager.
  2. RubinettoApri conOCondividere.
  3. ScegliereVisualizzatore GPX.
  4. SelezionareSemprese richiesto, per importazioni più rapide in seguito.

Risoluzione dei problemi

  • Tipo di file sbagliato- conferma che l'estensione è.gpx, non.kmlO.tcx.
  • App non nel menu Condividi— apri GPX Viewer una volta, quindi riprova.
  • Pista vuota— il file può contenere metadati ma nessun punto GPS; riesportare dall'app di origine.
  • Il file sembra sbagliato sulla mappa- Vederecome visualizzare GPX su una mappa.
