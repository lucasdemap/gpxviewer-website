So öffnen Sie GPX-Dateien auf iPhone und Android

Importieren Sie GPX-Routen aus Mail, Dateien oder Safari in den GPX Viewer.

2. September 2026

iOS und Android enthalten keinen integrierten GPX-Kartenviewer. Sie benötigen eine App wieGPX-Viewerdas versteht das.gpxFormat. Einmal installiert, Das Importieren einer Route erfordert ein paar Fingertipps durch das Freigabeblatt.

Open GPX on iPhone

Aus E-Mails oder Dateien

  1. Finden Sie die.gpxAnhang oder Datei.
  2. KlopfenAktie.
  3. WählenGPX-Viewer.
  4. Die Route erscheint sofort auf der Karte.

Von Safari

Tippen Sie auf einer Trail-Website auf einen GPX-Download-Link und geben Sie die heruntergeladene Datei dann für GPX Viewer frei Laden Sie es über den Download-Manager von Safari herunter oder speichern Sie es zunächst unter „Dateien“.

Apple Maps kann GPX nicht öffnen

Apple Maps importiert keine GPX-Dateien. Verwenden Sie stattdessen den GPX Viewer – er zeigt den gesamten Track an. Höhenprofil und Wegpunkte auf Standard-, Satelliten- oder Hybridkarten.

Öffnen Sie GPX auf Android

  1. Öffnen Sie den GPX-Anhang in Gmail oder Ihrem Dateimanager.
  2. KlopfenÖffnen mitoderAktie.
  3. WählenGPX-Viewer.
  4. WählenStetswenn Sie dazu aufgefordert werden, für schnellere Importe später.

Fehlerbehebung

  • Falscher Dateityp— Bestätigen Sie, dass die Erweiterung vorhanden ist.gpx, nicht.kmloder.tcx.
  • App nicht im Teilen-Menü— Öffnen Sie den GPX Viewer einmal und versuchen Sie es dann erneut.
  • Leere Spur— Die Datei enthält möglicherweise Metadaten, aber keine GPS-Punkte. Erneuter Export aus der Quell-App.
  • Die Datei sieht auf der Karte falsch aus- sehenSo zeigen Sie GPX auf einer Karte an.
